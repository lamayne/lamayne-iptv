# Changelog

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [SemVer](https://semver.org/).

## [0.1.1]

### Added
- **Actor filmography**: clicking an actor's name on a movie page now lists all of their movies available in your catalog, not only the ones whose page you already opened. The filmography comes from Wikidata; only the actor's name is sent, and only when you click it.

## [0.1.0] — first public release

### Added
- Player for **Xtream Codes** and **M3U** sources: Live TV, movies, series; several profiles.
- Playback with **mpv**: hardware decoding, picture-in-picture, fullscreen, keyboard shortcuts.
- **Programme guide (EPG)**: provider guide and public guide; manual update and per-channel check in Settings.
- Home page: "of the moment" recommendations (5 in rotation), favourite channels and series, **global search** (channels, movies, series).
- Resume playback; recently watched channels kept between launches.
- **Cast** to Google devices (Chromecast, Google TV) on the local network.
- Interface in **French, English and Spanish** (system language on first launch).
- First launch guides you to add a source.
